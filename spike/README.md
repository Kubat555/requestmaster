# spike

Черновой код этапа 0 (проверка основы). В продукт не переносится.

Что осталось и почему:

- `shell/` — пробник окна (Tauri + Svelte + CodeMirror, замеры запуска и большого ответа). Образцом для
  продукта больше не служит: настоящее окно — `src-tauri/` и `ui/` (план 1B «Окно: основа» выполнен).
  Остаётся только ради замеров: замеры целей раздела 10 спеки отложены в часть 3 этапа 1 («Окно: полнота»),
  а исходные значения сняты этим пробником — до тех пор его можно пересобрать и сравнить.
- `samples/` — образцы владельца для тестов на настоящих данных. В git не попадает (`.gitignore`).

Что удалено после этапа 1A:

- пробник формата Postman — его знания перенесены в `crates/rqm-postman`;
- пробник HTTP — его знания перенесены в `crates/rqm-http`.

Что удалено после этапа 2:

- пробник движка скриптов (`rquickjs`, прелюдия `pm.*`, байткод, лимиты) — его заменил crate
  `crates/rqm-script`.

Их выводы учтены в `docs/design.md`, код остаётся в истории git.
